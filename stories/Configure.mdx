  <div className="gs-section">
    <h2>Setup</h2>
    <p>Wrap your application with <code>MisDesignProvider</code>. Use the <code>Theme</code> enum to set the initial theme:</p>
    <pre className="gs-code">{`import { MisDesignProvider, Theme } from 'mis-design';

function App() {
return (

<MisDesignProvider theme={Theme.LIGHT}>
<YourApp />
</MisDesignProvider>
);
}`}</pre>
<div className="gs-note">
When <code>theme</code> is not provided, the provider defaults to the browser/system preference.
It also auto-mounts <code>NotificationStack</code> and <code>ToastStack</code> globally.
</div>
